# תמלול וסיכום – אפליקציית אנדרואיד אישית

## התחלה מהירה (5 צעדים)

1. חלץ את קובץ ה-ZIP לתיקייה (למשל `Documents\VoiceNotesAndroid`).
2. פתח Android Studio > Open > בחר את התיקייה הזו ואשר Trust. חכה שה-Sync יסתיים (פעם ראשונה לוקח כמה דקות).
3. Build > Build Bundle(s) / APK(s) > Build APK(s). כשמסתיים לחץ Locate: הקובץ `app-debug.apk`.
4. העבר את הקובץ לטלפון (כבל, Drive או מייל) ולחץ עליו להתקנה. אשר "התקנה ממקור לא ידוע" אם מתבקש.
5. פתח את האפליקציה > הגדרות > הדבק מפתח Claude (חובה לסיכום ותרגום) ומפתח Groq (לתמלול קובץ שמע). אשר הרשאות מיקרופון והתראות בהקלטה הראשונה.

אם ה-Build נכשל: העתק לי את שורות השגיאה האדומות מהחלון Build ואתקן.

תמלול: זיהוי הדיבור של אנדרואיד (Google). סיכום ותרגום: Claude דרך ה-API של Anthropic.

## בנייה (במחשב עם Android Studio)

1. התקן Android Studio (הגרסה העדכנית) מ-developer.android.com/studio.
2. פתח אותו: File > Open > בחר את התיקייה `VoiceNotesAndroid` (זו שמכילה את `settings.gradle.kts`).
3. חכה לסיום ה-Gradle Sync (בפעם הראשונה זה לוקח כמה דקות והוא יוריד כלים לבד). אם יופיע חלון עם "Install missing SDK", אשר.
4. כדי לקבל קובץ להתקנה: Build > Build Bundle(s) / APK(s) > Build APK(s). הקובץ יהיה ב-`app/build/outputs/apk/debug/app-debug.apk`.
5. העבר את ה-APK לטלפון (כבל, Drive, מייל). בטלפון אפשר "להתקין מקורות לא מוכרים" כשמתבקש, ואז פותחים את הקובץ ומתקינים.
   - או: חבר את הטלפון בכבל (עם "ניפוי באגים ב-USB" פעיל) ולחץ על Run (המשולש הירוק).

## מפתח API

1. היכנס ל-console.anthropic.com, הוסף אמצעי תשלום וצור API key.
2. פתח את האפליקציה > הגדרות > הדבק את המפתח.
   המפתח נשמר בטלפון בלבד. החיוב ב-API נפרד מהמנוי ל-Claude.

## הקלטה ברקע ומגבלת זמן

- ההקלטה רצה בשירות רקע עם התראה קבועה, אז היא ממשיכה גם כשעוברים לאפליקציה אחרת או כשהמסך כבוי.
- ההקלטה נעצרת אוטומטית שעה מההפעלה.
- 5 דקות לפני הסיום מופיעה התראה בולטת עם ספירה לאחור וכפתור "הארך ב-30 דק׳". אותו כפתור מופיע גם באפליקציה.
- אפשר להאריך שוב ושוב, וכל הארכה מוסיפה חצי שעה.
- בפעם הראשונה אשר הרשאות מיקרופון והתראות.
- חשוב: בהגדרות המכשיר (אפליקציות > תמלול וסיכום > סוללה) בחר "ללא הגבלה" / "Unrestricted", כדי שחיסכון בסוללה לא יעצור את ההקלטה (במיוחד בסמסונג, שיאומי, אופו).
- אם נכנסת שיחת טלפון או אפליקציה אחרת תפסה את המיקרופון, ההקלטה עלולה להיעצר.

## שמירת שמע

- בכל הקלטה נשמר גם קובץ שמע (AAC, כ-20MB לשעה) בתיקייה `Music/VoiceNotes` בטלפון, בלי קשר לתמלול.
- אפשר לנגן ולשתף אותו מהאפליקציה, או למצוא אותו באפליקציית הקבצים.
- אנדרואיד לא אוהב ששני רכיבים משתמשים במיקרופון יחד. האפליקציה מקליטה את השמע קודם, ואם היא מזהה שהשמע הושתק בגלל תמלול Google, היא מכבה את התמלול החי והשמע ממשיך להישמר.
- אם התמלול החי כמעט אף פעם לא עובד אצלך, בטל אותו בהגדרות ("תמלול חי"), ותמלל את קובץ השמע אחר כך.
- הפרויקט דורש אנדרואיד 10 ומעלה.

## תמלול מקובץ שמע (לא Claude, ואפשר בחינם)

- כפתורים: "תמלל את ההקלטה האחרונה" או "תמלל קובץ שמע אחר…".
- ברירת המחדל: Groq (Whisper large-v3-turbo), שיש לו שכבה חינמית עם מגבלות. מפתח מ-console.groq.com, בלי כרטיס אשראי (בדוק במסך ההרשמה).
- מגבלות חינמיות (נכון למועד הכתיבה, ייתכן שישתנה): כ-7,200 שניות שמע בשעה וכ-28,800 ביום, וקובץ עד 25MB. האפליקציה חותכת לקטעים של 20 דקות, אז זה מתאים.
- למעבר ל-OpenAI (בתשלום): בהגדרות שנה את הכתובת ל-`https://api.openai.com/v1` ואת המודל ל-`whisper-1`, והדבק מפתח OpenAI.
- הקובץ עולה לשרתי הספק. אל תשתמש בזה לדיונים שאסור להעביר לצד שלישי.
- הקלטה ארוכה נחתכת אוטומטית ומחוברת חזרה לטקסט אחד. השאר את האפליקציה פתוחה עד הסיום.
- שפת התמלול נלקחת מבורר "שפת הדיבור" שבראש המסך.
- התמלול נכנס לשדה התמלול, ומשם אפשר לסכם ולתרגם עם Claude.

## הערות

- שם המודל בהגדרות: ברירת המחדל `claude-sonnet-5-5`. לחיסכון אפשר `claude-haiku-5-5`.
- זיהוי הדיבור מופסק אחרי שתיקה, והאפליקציה מפעילה אותו מחדש לבד. בחלק מהמכשירים נשמע צליל קצר בכל הפעלה.
- אין שמירה של קובץ שמע, רק טקסט.
